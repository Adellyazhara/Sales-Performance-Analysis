# Sales-Performance-Analysis
Overview performa penjulan berdasarkan sales, product, customer, city, payment method, rating, dan time period.

# Dataset
Dashboard menggunakan dataset transaksi penjualan supermarket yang berisikan 1.000 transaksi dengan:
- Sales/Transaction (invoice ID, unit price, quantity, tax 5%, total, cogs, gross income, gross margin percentage)
- Customer (customer type, gender, rating)
- Product (product line)
- Location (branch, city)
- Date & time (date, time)
- Payment (payment)
